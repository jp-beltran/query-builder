# Query Builder

Projeto desenvolvido para acompanhar e praticar os conteúdos sobre Query Builder no curso Fullstack da Rocketseat.

## Conteúdos abordados

- Introdução ao Query Builder e apresentação da aplicação
- Instalação e configuração do Knex.js
- Migrations: criação de tabelas, alteração de tabelas e rollback
- Conexão com o banco de dados e scripts de execução
- Operações de insert, select, update e delete
- Uso de Knex Raw
- Seeds
- Relacionamentos entre tabelas
- Cadastro e consulta de módulos
- Consultas com `JOIN`
